# Cast Recorder

A lightweight screen recorder for Windows, with GPU capture and hardware encoding.

- Instant replay: save the last N seconds with a hotkey
- Window or monitor capture, live preview, pause
- H.264 / HEVC / AV1 hardware encoding (NVENC, AMF, QuickSync), software fallback
- Separate audio tracks for system audio and microphone, noise suppression
- MKV → MP4 remux, global hotkeys
- Crash-safe recording, light and dark themes

**Download:** [latest release](https://github.com/NeusByCast/cast-recorder/releases/latest)
